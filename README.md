# تماريني

تطبيق Flutter لتسجيل التمارين وبرامجها ومتابعة التطور. يعمل بدون إنترنت، والبيانات محفوظة على الجوال فقط.

## المزايا
- برامج تمارين (مثل «البلانش») بأيام محددة من الأسبوع
- لكل تمرين: اسم، وعدّات أو مؤقت (ثبات)، وجولات، وراحة بين الجولات
- شاشة تمرين حيّة: مؤقت وعدّ تنازلي وراحة، وكل جولة تُسجَّل تلقائياً
- جدول تطور: رسم بياني وأفضل رقم وسجل الجلسات
- وضع داكن وفاتح، وصوت واهتزاز اختياريان

## الاعتماديات
حزمة واحدة فقط: `shared_preferences`

## البنية
- `lib/main.dart` نقطة التشغيل والتنقل السفلي
- `lib/theme.dart` الثيم والعناصر المشتركة
- `lib/models/` التمرين والبرنامج وسجل الجلسة
- `lib/services/storage_service.dart` الحفظ المحلي
- `lib/pages/` الصفحات
- `lib/widgets/progress_chart.dart` الرسم البياني


## المجسم العضلي ثلاثي الأبعاد
- صفحة تفاصيل التمرين تعرض مجسماً ثلاثي الأبعاد يمكن تدويره وتكبيره، مع تبديل زاوية العرض الأمامية والخلفية.
- يحتاج المجسم إلى اتصال بالإنترنت لتحميل ملف GLB من مستودع النموذج؛ باقي بيانات التطبيق تبقى محلية.
- النموذج مشتق من بيانات BodyParts3D / DBCLS وZ-Anatomy. ترخيص النموذج CC BY-SA؛ أي نسخة معدلة من ملف النموذج يجب أن تحتفظ بالترخيص نفسه وبالإسناد إلى المصدرين. المصدر: https://github.com/WaterCMY/anatomy-3d
- ملاحظة: أسماء العضلات المرتبطة بالتمرين تظهر أسفل المجسم، لكن التلوين الدقيق لكل عضلة داخل الشبكة ثلاثية الأبعاد يتطلب ربط أسماء العضلات بأسماء الـ meshes في ملف GLB، ولم يتم تفعيله في هذه النسخة.
